TraceHealer desktop client

This shell connects to the TraceHealer service you configure. Run progress, incidents, and healing evidence come from the server over authenticated HTTP.

Repository execution, model calls, and every secret stay server-side. The session token is stored only in the operating system credential vault (Windows Credential Manager, macOS Keychain, or Linux Secret Service) — never in web storage.

tracehealer://incident/<id> and tracehealer://run/<id> deep links open the matching run.
